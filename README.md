# Funded Slots Roadmap

One static page: how many prop-firm evals to buy per firm today, what they cost, and the cash plan for the next 12 weeks.

Live page: https://3bdotrades.github.io/ (G1) and https://3bdotrades.github.io/?fleet=v2 (V2 fleet). Both read their account counts from the same fleet dashboard. Prices and payouts are set in `index.html`; the three rates can be changed on the page and are remembered in your own browser.
