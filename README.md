# Funded Slots Roadmap

One static page: how many prop-firm evals to buy per firm, what they cost, and when payouts land over the next 12 weeks. Inputs are editable in the page and remembered in your own browser only.

Live page: https://3bdotrades.github.io/ (G1) and https://3bdotrades.github.io/?fleet=v2 (V2 fleet). Both read the same fleet dashboard; each keeps its own numbers in the browser.
